# Beauty Unique Outdoor Day Spa

Plain static site: HTML, one CSS file, one JS file, photos. No build step.

## Deploy on GitHub Pages
1. Upload everything in this folder to the **root** of a GitHub repository (branch `main`).
2. Repo **Settings → Pages → Build and deployment → Source: Deploy from a branch → `main` / `/ (root)`** → Save.
3. After a minute the site is live at `https://<username>.github.io/<repo>/`.

## Custom domain (only when ready)
Add a file named `CNAME` containing `beautyuniqueoutdoorspa.com`, point the domain's DNS at GitHub Pages, then tick **Enforce HTTPS**.

## Editing
- Prices/treatments: `treatments.html` · Packages: `packages.html` · Policies: `etiquette.html`
- New photos: drop into `img/` and reference as `img/<file>`
- The header and footer are repeated on each page; change all four.
